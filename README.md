
# GC Content Analyzer

## About the Project
A Python-based bioinformatics tool for analyzing
GC content in DNA sequences using FASTA files.

## Objectives
- Calculate DNA sequence length.
- Count A, T, G and C nucleotides.
- Calculate GC content percentage.
- Calculate AT content percentage.
- Visualize nucleotide composition.
- Generate CSV reports.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib

## Methodology

GC Content (%) = (G + C) / (A + T + G + C) * 100

## Input
FASTA formatted DNA sequences.

## Output
- Nucleotide composition table
- GC content percentage
- AT content percentage
- GC content graph
- CSV report

## How to Run
1. Open the notebook in Google Colab.
2. Upload a FASTA file.
3. Run the Python cells.
4. View the analysis and download the CSV report.
